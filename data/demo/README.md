# Демонстрационные выгрузки данных

Файлы в этой папке — **синтетические демонстрационные данные**, имитирующие
типовые выгрузки ведомственных информационных систем (раздел 5 ТЗ). Они
используются модулем «из коробки», чтобы диалоговый мастер и цепочки
источников можно было опробовать без реального доступа к
государственным ИС и порталу НСК (реквизиты доступа к которым, согласно
разделу 13 ТЗ, уточняются на этапе обследования).

**Значения НЕ являются официальной статистикой** и не должны
использоваться для реальных расчётов Индекса — при внедрении модуля эти
файлы заменяются реальными выгрузками или подключениями к API согласно
разделу 5 ТЗ.

| Файл                          | Имитирует источник (раздел 5 ТЗ)                          | Показатели            |
|--------------------------------|-------------------------------------------------------------|------------------------|
| `geodesy_dem_export.csv`       | Госагентство геодезии и картографии / открытые ЦМР          | GEO.height, GEO.slope  |
| `transport_gis_export.csv`     | Минтранс КР, ГИС-анализ (в т.ч. OSM)                        | ACC.*                  |
| `nsc_demographics_export.csv`  | Портал Нацстаткомитета КР (локальный fallback при недоступности сайта) | DEM.* |
| `social_services_export.csv`   | Минобразования КР, Минздрав КР                              | SERV.*                 |
| `infra_export.csv`             | Госагентство связи, Минтранс КР, водное хозяйство           | INFRA.*                |
| `eco_risks_export.csv`         | МЧС КР, Институт сейсмологии НАН КР                          | ECO.*                  |
| `econ_export.csv`              | Минтруда КР, Минсельхоз КР, ГНС/Соцфонд КР (локальный fallback для демо REST API) | ECON.* |
